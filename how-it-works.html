macdroid-tether-extreme · uplink.sh

The phone's own data, on your Mac, over a cable

Every app on the Mac uses the phone's mobile data through the USB cable. Hotspot and USB tethering aren't involved, so it isn't counted as hotspot. TCP and UDP both work, and it cleans up after itself even if something crashes.

01The path

One cable. Two copies of sing-box, one on each end. Everything leaves through the phone's own connection.

on the Mac on the phone traffic

02The three things that make it work

Each one fixes a specific way earlier versions failed.

Not hotspot

The phone opens the connections

Hotspot and tethering forward another device's packets. Here a normal process on the phone opens each connection itself, the same path any app uses. Android counts all of it as the phone's own use.

UDP works

UDP rides inside the TCP pipe

adb forward only carries TCP. UDP-over-TCP packs each UDP flow into it, so DNS, QUIC, NTP, calls and WireGuard all get through, not just web pages.

Wi-Fi optional

macOS treats it as the real connection

A tiny helper makes the uplink the first-choice DNS and the primary connection. With Wi-Fi off, apps don't decide you're offline, and turning Wi-Fi on or off can't take the route back.

03Proof it isn't tethering

Read straight from the phone with adb shell dumpsys during a session.

Billing is still the carrier's call. Deep inspection could spot that the content comes from a Mac. The final word is your carrier's hotspot-usage counter: note it, use the uplink, and check that it hasn't moved.

04How we got here

Two earlier designs, both removed and both still in git history.

  1. 1
    Userspace RNDIS driverMade Android USB tethering work on Apple Silicon. It worked, but tethering is the hotspot meter.
  2. 2
    Every Proxy + tun2socksUsed the phone's on-device path, but the adb pipe is TCP-only. DNS and all other UDP failed as soon as Wi-Fi went off.
  3. 3
    sing-box on both ends (now)UDP inside TCP, DNS answered locally, macOS told it's the primary connection. Nothing is installed on the phone and no root is needed.

06Using it

The password is needed once, for install. On/off after that needs none, from the terminal or Raycast.

# once
./uplink.sh setup            # fetch sing-box, build helper, copy to phone
sudo ./uplink.sh install     # launchd job + passwordless start/stop

# day to day — no sudo
./uplink.sh toggle           # or Raycast: "Phone Uplink Toggle"
./uplink.sh status           # 📱 Phone uplink ON · 140ms · exit 172.56.x.x
./uplink.sh check            # exit IP, DNS, UDP, primary, MagicDNS
